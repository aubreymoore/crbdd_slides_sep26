- Feeding damage to coconut palms is caused only by adults which bore into the crown to feed on sap. - CRB adults feed about once per month. They feed in a bore hole for only a few days and then leave the tree. - CRB are not true defoliators. Damage is caused to developing leaves inside the crown as the beetle bores through them on its way to the sap. - When these fronds emerge from the crown and expand, several weeks later, distinctive v-shaped cuts become apparent and can be seen over a distance of several hundred meters. - Tree mortality occurs only when the single meristem at the base of the the crown is damaged. But this rarely happens at low population levels. - Referring to the damaged trees in these photos as being "infested" is incorrect. There probably were no beetles inside them when the photos were taken. - All of these trees, accept for the dead one in the background, would have survived if further damage had been stopped using insecticides or some other means. - Removal of live trees, even heavily damaged ones, is not recommended. - However, dead trees, such as the one in the background of the right-hand photo, should be removed and processed so they don't become breeding sites. - But there is an exception to this. Leaving some dead palms standing is recommended where CRB populations are being controlled with OrNV because breeding sites in dead standing palms are important for virus transmission. - END
- The system I built runs free open source software. - Free public repositories on GitHub are used to share code and output, which includes interactive web maps. - This slide lists ingredients. - Python: my favorite programming language, which is named after my favorite comedy show, Monty Python's Flying Circus - SpatiaLite: an embedded database with geospatial superpowers - QGIS: Quantum geographic information system. QGIS can read data directly from a SpatialLite database. - SAM3: Meta's Segment Anything Model - GitHub repositories are used for storing and sharing source code and results
- let's have a look at inputs and outputs. We will consider the processing pipeline as a black box right now. - INPUTS - input is simply a list of links to images available on the host machine or anywhere on the web - images may come from roadside CRB damage surveys or random images harvested from the web - images can be in any format and may contain embedded GPS coordinates - OUTPUTS - Outputs include a SpatiaLite database populated with results, a statistical report, and a web map - Outputs are automatically pushed to a public GitHub repository - END
- Now let's open the black box containing the pipeline. - Care must be taken lots of snakes live inside. - In step 1, latitude and longitude are extracted from the image file if GPS coordinates have been embedded - In step 2, the SAM3 model is used to locate all coconut palms and extract tree shapes as polygons - In the remaining steps, I find and classify CRB feeding damage using conventional shape analysis techniques from the field of computer vision, implemented using Python with the help of SpatiaLite spatial functions. - Note that SAM is the only AI model that I used. It does a great job of finding coconut palm trees in images. - In previous work, I tried to train an AI objector detectors to find damage in the form of v-shaped cuts with limited success. - I have recently realized that v-shaped cuts **not objects** in the same sense that donut holes are not objects. - That is why I switched to computer vision techniques for this task.
- Coconut palms in images are detected using Meta's SAM3 model. - This model is pretrained on millions of images and it understands english. - There is no need for annotation or training. - PAUSE - On the left is an image published on the web by the NY Times - I politely prompted SAM3 to find "coconut palm tree" in this image and got the results on the right. - These results blew my mind. - SAM3 found 2 coconut palms with high confidence and segmented them from the background with high enough resolution to see feeding damage - END
