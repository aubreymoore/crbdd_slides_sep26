- Feeding damage to coconut palms is caused only by adults which bore into the crown to feed on sap. - Beetles are not true defoliators. The damage is caused to developing leaves inside the crown as beetle bore through them on their way to the sap. - When the fronds emerge from the crown several weeks later, they have these distinctive v-shaped cuts which can be seen for several hundred meters. - Tree mortality occurs only when the single meristem at the base of the the crown and this rarely happens at low population levels. - It is not correct to refer to palms like those in these images as being "infested". CRB adults feed about once per month, feeding in a bore hole only for a few days. - Referring to these trees as "infested" is incorrect. Chances are that no beetles where inside them when these photos were taken. - All of these trees, accept for the dead one in the background, would have survived if further damage was stopped. - Dead trees should be removed and processed so they don't become breeding sites for generations of grubs. - But there is an exception to this. Leaving some dead palms standing is recommended where CRB populations are being controlled with OrNV because these breeding sites provide an important transmission site for the virus.
- this system is built using FOSS - let's have a look at inputs and outputs. We will consider the processing pipeline as a black box right now. - input is simply a list of images available on the host machine or anywhere on the web - images may come from roadside CRB damage surveys of they may come from from the web - you are probably aware of the recent discovery of CRB in Mexico from web images by our AgResearch New Zealand colleagues - images can be in any format and may contain embedded GPS coordinates - the main output is a SpatiaLite database which is a SQLite database with spatial superpowers - it is a very powerful stand alone database which can be run just about anywhere - the pipeline populates the database with data extracted from the images including dates, locations, and damage classes - these database generates statistical reports - Quantum GIS or QGIS can read the SpatiaLite data base directly and it is used to generate an interactive web - outputs are automatically published an open access GitHub repository
- Now let's open the black box containing the pipeline. - You have to be very careful because there are lots of snakes inside the box. - In step 1, latitude and longitude are extracted from the image file if GPS coordinates have been embedded - In step 2, Meta's SAM3 model is used to locate all coconut palms and extract tree shapes as polygons - In step 3, damage shapes are extracted from each tree and saved as polygons - In steps 4 and 5 tree shapes and damage shapes are classified - Note that SAM is the only AI model that I used - The last 3 steps do not use AI but instead, they use conventional shape analysis techniques from the field of computer vision implemented using Python with the help of SpatiaLite spatial functions. - In previous work, I tried to train an AI objector to find damage in the form of v-shaped cuts with limited success. - I have recently realized that v-shaped cuts should be analyzed as simple shapes because **they are not objects** in the same sense that donut holes are not objects.
- Coconut palms in images are detected using Meta's SAM3 model. - SAM stands for Segment Anything Model. - This model is pretrained on millions of images and it understands english. - On the left is an image published on the web by the NY Times - I politely asked SAM3 to find "coconut palm tree" in this image and got the results on the right. - These results blew my mind. - SAM3 found 2 coconut palms with high confidence and segmented them from the background
